# Grade Ledger

Fall 2026 grade tracker: course grades weighted by each syllabus, score entry with category averages, and what-if sliders that show the score needed for a target grade. Installable web app (PWA), run locally: open `index.html`, or run `node serve.js` from the folder above and visit http://localhost:5175.

All scores are stored only on each device (browser localStorage); nothing is sent anywhere. Use Settings → Export/Import to move them between devices.
